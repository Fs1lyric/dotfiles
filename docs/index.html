What’s in the repo

Every config, in one place

home/ mirrors your home folder, so each path below is exactly where the file lands. The Firefox and Zen folders go into each browser’s profile, wherever it lives.

  • ▸.config/hypr/

    Hyprland in Lua: monitors, input, look and feel, keybinding overrides.

  • ▸.config/omarchy/

    Bar layout, hooks, the menu, the Solitude wallpaper and a custom app-launcher bar widget.

  • ▸.config/nvim/

    LazyVim with neo-tree and Python extras; follows the system theme live.

  • ▸.config/kitty/

    The main terminal. Alacritty, Ghostty and foot configs are there too.

  • ▸.config/tmux/

    Omarchy’s tmux setup: sessions, splits and the theme.

  • ▸.config/starship.toml

    A quiet prompt: folder, branch and git status, then ❯.

  • ▸firefox/

    userChrome.css for a Zen-style Firefox: vertical tabs that expand on hover, compact toolbars, split view.

  • ▸zen/

    The same custom CSS for the Zen browser.

  • ▸.config/mise/

    Toolchain pins: Node, Python, gh, plus Claude Code, Codex and opencode.

  • ▸.config/fastfetch/

    The boxed Hardware / Software readout.

  • ▸.config/doom/

    Doom Emacs, for the days Neovim isn’t enough.

  • ▸.bashrc

    Omarchy defaults plus aliases. Secrets load from an untracked ~/.bashrc.secrets.

On a fresh Omarchy install

Install it

The script copies files; it never deletes. Anything it would overwrite goes to ~/.dotfiles-backup/<timestamp>/ first, so you can undo it.

  1. Clone the repo

    ❯ git clone https://github.com/Fs1lyric/dotfiles ~/dotfiles

  2. Open Firefox and Zen once

    Each browser creates its profile folder on first launch. The script needs it to exist to put the CSS inside.

  3. Run the installer

    ❯ ~/dotfiles/install.sh

  4. Add your own keys

    API keys never go in the repo. Put them in ~/.bashrc.secrets, which .bashrc loads and git ignores.

    ❯ $EDITOR ~/.bashrc.secrets

  5. Sign in and install the tools

    ❯ gh auth login && gh auth setup-git && mise install

    Then log out and back in so Hyprland and the bar pick everything up.
